# Freelancer Data Analyzer

## Описание

Freelancer Data Analyzer - это консольное приложение на Python для анализа статистических данных о фрилансерах. Программа позволяет обрабатывать запросы на естественном языке к набору данных о заработках фрилансеров, их опыте, географическом распределении, способах оплаты и других параметрах.

## Основные возможности

- Загрузка и обработка данных из CSV-файла с информацией о фрилансерах
- Генерация статистики по различным параметрам (способы оплаты, регионы, уровень опыта и др.)
- Обработка запросов на естественном языке с использованием OpenAI API (GPT-3.5 Turbo)
- Режим эмуляции ответов при отсутствии API-ключа

## Требования

- Python 3.6+
- Pandas
- NumPy
- OpenAI Python SDK
- python-dotenv

## Установка

1. Клонируйте репозиторий или скачайте исходный код
2. Установите необходимые зависимости:

```bash
pip install pandas numpy openai python-dotenv
```

3. Создайте файл `.env` в корневой директории проекта и добавьте свой API-ключ OpenAI:

```
OPENAI_API_KEY=ваш_ключ_api
```

## Использование

### Запуск программы

```bash
python freelancer_analyzer.py --data путь_к_файлу_данных.csv
```

Если аргумент `--data` не указан, программа использует файл `freelancer_earnings_bd.csv` по умолчанию.

### Взаимодействие с программой

После запуска программы вы увидите приглашение для ввода вопроса. Введите запрос на естественном языке, касающийся данных о фрилансерах, например:

- "Какие регионы имеют самый высокий средний доход?"
- "Сколько фрилансеров-экспертов выполнили менее 100 проектов?"
- "Как влияет прием криптовалюты на заработок фрилансеров?"

Для выхода из программы введите `выход`, `exit`, `quit` или `q`.

## Структура данных

Программа работает с CSV-файлом, содержащим следующие столбцы (в указанном порядке):

1. `Freelancer_ID`: Идентификатор фрилансера
2. `Job_Category`: Категория работы
3. `Platform`: Платформа
4. `Experience_Level`: Уровень опыта фрилансера
5. `Client_Region`: Регион клиента
6. `Payment_Method`: Способ оплаты
7. `Job_Completed`: Количество выполненных проектов
8. `Earnings_USD`: Заработок в USD
9. `Hourly_Rate`: Почасовая ставка
10. `Job_Success_Rate`: Процент успешных проектов
11. `Client_Rating`: Рейтинг клиента
12. `Job_Duration_Days`: Продолжительность работы в днях
13. `Project_Type`: Тип проекта
14. `Rehire_Rate`: Процент повторных наймов
15. `Marketing_Spend`: Расходы на маркетинг

## Особенности работы

- При наличии API-ключа OpenAI программа использует GPT-3.5 Turbo для обработки запросов
- В режиме эмуляции (при отсутствии API-ключа) программа предоставляет предопределенные ответы на определенные типы запросов
- Программа предварительно обрабатывает данные для создания статистического контекста, используемого в запросах к языковой модели
